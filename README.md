# NovaGram

Неофициальный Android-клиент Telegram на основе открытого исходного кода Telegram for Android.

> NovaGram — независимый проект, не связанный с Telegram FZ-LLC. Название и оформление должны ясно показывать, что это сторонний клиент.

## Статус

Сейчас репозиторий содержит оригинальную векторную иконку NovaGram, Java-основу Liquid Glass палитр и поверхностей, локальные настройки прозрачности и reduced motion, скрипт наложения изменений и workflow сборки поверх исходников Telegram. Полная интеграция визуальных компонентов во все экраны, а также подключение настроек чатов и приватности выполняются поэтапно; наличие дизайн-классов само по себе не означает, что весь интерфейс уже переведён на Liquid Glass.

## Возможности в плане

- Брендинг NovaGram: имя приложения и отдельный package ID.
- Собственные цветовые пресеты.
- Дополнительные настройки интерфейса чатов.
- Управление анимациями и режим уменьшенного движения.
- Настройки приватности, которые используют только поддерживаемые Telegram механизмы и не обещают скрыть данные, которые протокол передаёт собеседнику или серверам.

## Сборка

GitHub Actions запускается вручную через Actions → Android build → Run workflow после добавления секретов.

В репозитории GitHub открой Settings → Secrets and variables → Actions и добавь:

- NOVAGRAM_API_ID — числовой API ID своего приложения.
- NOVAGRAM_API_HASH — API hash своего приложения.

Получить собственные значения можно на https://my.telegram.org/apps. Telegram требует, чтобы стороннее приложение использовало собственный api_id; тестовые реквизиты из исходников официального клиента не предназначены для пользовательских приложений. Не публикуй значения в исходниках, README, Issues или коммитах. Учти, что реквизиты, встроенные в распространяемый APK, технически могут быть извлечены из него.

Для Firebase Cloud Messaging позднее понадобится собственный google-services.json; без него CI собирает тестовую версию без конфигурации Firebase push.

Workflow собирает debug APK для тестирования, не подписанный production-релиз.

## План работ

1. Bootstrap репозитория и автоматическая сборка исходной базы.
2. Проверка отдельного package ID и брендинга NovaGram.
3. Подключение цветовых пресетов к реальным экранам.
4. Подключение настроек чатов и анимаций.
5. Аудит приватности, разрешений и сетевого поведения.
6. Настройка Firebase и отдельной release-подписи.
